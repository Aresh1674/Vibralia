# Vibrostase · version web

Version navigateur de Vibrostase, publiée avec GitHub Pages (utile surtout sur iPhone : Safari › Partager › « Sur l'écran d'accueil »).

| Chemin | Rôle |
|---|---|
| `index.html` | L'appli (même page que l'APK) |
| `sons/` | Les 101 enregistrements intégrés (CC0, Freesound) et `SOURCES.txt` |
| `tuto.mp4` | La vidéo de prise en main (Réglages › Aide) |

Rien d'autre ne doit être déposé à la racine : la page cherche les sons dans `sons/`.
Ce dépôt est public : il ne contient ni clé ni mot de passe. Le projet Android (avec la clé de signature) est dans le dépôt privé `Vibrostase`.
